# 🎮 GpuBench - Android GPU 性能测试

一个简洁的 Android GPU 跑分应用，实时显示渲染性能。

## ✨ 功能特点

- 📊 **实时 FPS 显示** - 大字号帧率显示，颜色随性能变化（绿/黄/红）
- 🔺 **三角形渲染测试** - 10,000 个旋转的彩色球体，测试 GPU 渲染能力
- 🎯 **全屏沉浸体验** - 横屏全屏显示，专注于性能测试
- ⚡ **简单操作** - 选择 API，点击开始，立即测试

## 🚀 使用方法

1. 下载并安装 `app-debug.apk`
2. 打开应用
3. 选择图形 API（OpenGL ES 或 Vulkan）
4. 点击 **"开始测试"**
5. 观察实时 FPS 和帧时间

## 📊 测试指标

| 指标 | 说明 |
|------|------|
| FPS | 每秒帧数，≥55 为流畅（绿色），≥30 为一般（黄色），<30 为卡顿（红色） |
| 帧时间 | 每帧渲染时间（毫秒） |
| 三角形数 | 每帧渲染的三角形数量 |

## 🔧 技术规格

- **渲染引擎**: OpenGL ES 3.2 / Vulkan 1.3
- **测试场景**: 10,000 个 PBR 着色球体
- **最低系统**: Android 7.0 (API 24)
- **架构支持**: arm64-v8a, armeabi-v7a
